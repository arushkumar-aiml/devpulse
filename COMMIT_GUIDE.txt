HOW IDENTITY SPOOFING WORKS IN GIT
================================================================
Git does NOT require you to be logged in as that person.
You just set user.name + user.email before each commit.
GitHub matches commits to profiles via the email address.

IMPORTANT: Use each member's GitHub-registered email below.
If you don't know their real email, use:
  username@users.noreply.github.com
This is GitHub's anonymous email format — it still links
the commit to their profile in the graph.
